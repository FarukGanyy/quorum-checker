# Quorum Checker Contract

A governance utility contract that ensures proposals reach a minimum level of
participation before they can be approved or executed.

## Key Functions
- `set-quorum` — Define required quorum threshold
- `check-quorum` — Verify if participation meets quorum
- `get-quorum` — Retrieve current quorum configuration
- `record-participation` — Track voting participation metrics
- `is-quorum-met` — Return boolean quorum status for a proposal

Designed for DAOs and governance systems requiring minimum voter participation guarantees.
